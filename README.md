## 🎯 Selected Projects

### 🔍 **UNISEARCH – Cross-Modal Academic Search Engine**  
Unified search across lecture transcripts, video keyframes, images, and research papers using multimodal embeddings, FAISS, BM25, and a reranking model.

### 🧮 **Explainable VQA for Education**  
Visual question answering system with attention maps and feature‐importance explanations to enhance interpretability and trust in educational applications.

### 🧠 **Early Dementia Detection (Speech + ML + RL)**  
Built a speech-based cognitive assessment system that detects early signs of decline using embedding models, RL-based evaluation, and clinical-dataset training.

### ⚖️ **Legal Document RAG Assistant**  
Retrieved and summarized information from scanned legal documents (OCR → vector retrieval → transformer summarization), making legal content accessible and searchable.
